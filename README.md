# REF WEB — масштабный фикс

Статический многостраничный сайт на HTML, CSS и Vanilla JavaScript.

## Что изменено

- полностью заменён главный экран: крупный текст, три CTA, преимущества и интерактивная аналитическая карточка;
- аналитическая карточка анимирует графики и цифры, реагирует на наведение и переворачивается по клику;
- хедер уплотнён, пункт «Для предпринимателей» переименован в «Бизнесу»;
- блок «Кому помогаем» уплотнён и адаптирован под сетку 3×2;
- блок «Как это работает» собран в новую композицию: текст слева, система и пояснения справа;
- процесс переделан в горизонтальный ручной ползунок из шести этапов;
- по клику на этап открывается полноэкранное окно с подробностями;
- подбор услуги возвращён к крупным пропорциям HP, с линейными иконками и отдельной тёмно-серой сводкой;
- страница услуг приведена к строгой структуре HP;
- отключены липкие панели и автоматическое «подтягивание» секций при прокрутке;
- интерактивная схема Landing Page восстановлена в правильных пропорциях;
- калькулятор прогноза получил толстые синие ползунки, анимацию и оформленные результаты;
- пакеты увеличиваются и получают тень только при обычном наведении;
- контакты получили единый набор линейных иконок;
- по всему сайту применены почти прямые углы: 0–2 px, кроме функционально круглых элементов;
- палитра ограничена белым, синим и графитово-чёрным;
- проверены разрешения 375 px, 768 px, 1366×768, 1536×864 и 1920×1080;
- горизонтального переполнения на проверенных страницах нет.

## Запуск

Откройте `index.html` в браузере или разместите содержимое папки на любом статическом хостинге.

Формы работают в демонстрационном режиме и не отправляют данные на сервер.
